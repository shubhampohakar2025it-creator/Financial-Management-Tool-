
# 🚀 FinPilot — Financial Management Web Application

## 🎥 Demo Video
👉 https://youtu.be/wBkR4ovBbrw?si=QLvGQcLqk0OZPHre


FinPilot is a Figma-designed personal finance web application that helps users manage their money easily through expense tracking, budgeting, and savings goals. It is designed with a simple and clean interface so that anyone (even non-technical users) can use it without confusion.
